# email-marketing-analytics-test

### 🧩 Overview
This repository contains a solution for an email marketing analytics test task.

### Context
- Calculation of core email marketing metrics based on raw event data, including Delivery Rate, Open Rate, Click-to-Open Rate (CTOR) and Unsubscribe Rate, using correct aggregation of events rather than precomputed ratios.
- Analysis of email campaign performance over time to assess delivery quality, audience engagement and user reaction to email content.
- Subject line performance analysis with aggregation by email subject, selection of the best-performing subject based on Open Rate as the primary metric, with Unsubscribe Rate used as a protective metric to avoid negative user impact.
